    Section 1.1 Introduction to Probabiliy & Statistics

    Objectives

    Students will be able to...
    🔗
    1. Compute simple classical probabilities.
      🔗
      🔗
    2. Use the addition rule to compute complementary and compound probabilities.
      🔗
      🔗
    3. Distinguish between populations and samples.
      🔗
      🔗
    4. Distinguish between parameters and statistics.
      🔗
      🔗
    🔗

    Subsection Intro to Probability

    Definition 1.1.1.

    In probability & statistics, we call procedures with measureable outcomes experiments.
    🔗
    🔗

    Definition 1.1.2.

    An event is any collection of results or outcomes of a procedure. When that event cannot be broken down into further logical components, we call the event simple. Otherwise, that event is called compound.
    🔗
    🔗

    Definition 1.1.3.

    The sample space for an experiment is the collection of all possible simple events.
    🔗
    🔗

    Definition 1.1.4.

    Consider conducting an experiment \(n \) times. The number of times an event \(E \) occurs is called its relative frequency. From this experminet, we would say \(E\) has relative probability
    \begin{equation*} \prob(E) = \frac{\text{frequency}}{n}. \end{equation*}
    🔗
    🔗

    Definition 1.1.5.

    Let \(E \) be an event from an expermient with \(n\) simple events. The (classical) probability of \(E\) occuring is given by
    \begin{equation*} \cal{P}(E) = \frac{\text{number of ways } E \text{ can occur}}{n} \end{equation*}
    🔗
    🔗

    Theorem 1.1.6.

    As a procedure is repeated more often, the relative probabilities of all events in the sample space approach their classical probabilities.
    🔗
    🔗

    Theorem 1.1.7.

    Let \(E, F\) be events. Then
    \begin{equation*} \cal{P}(E \ \text{or} \ F) = \cal{P}(E) + \cal{P}(F) - \cal{P}(E \text{and} \ F). \end{equation*}
    🔗
    🔗

    Checkpoint 1.1.8.

    Verify the addition rule by comparing regions in a Venn diagram.
    🔗
    🔗

    Definition 1.1.9.

    Two events are disjoint (mutually exclusive) if they cannot occur simultaneously.
    🔗
    🔗

    Checkpoint 1.1.10.

    Show that if \(E\) is disjoint from \(F\text{,}\) then
    \begin{equation*} \cal{P}(E \ \text{or} \ F) = \prob(E) + \prob(F). \end{equation*}
    🔗
    🔗

    Checkpoint 1.1.11.

    Consider the experiment of rolling a fair 6-sided die and recording the result. Let \(E\) be the event we roll a 1. Let \(F\) be the event we roll less than 3.
    🔗

    (a)

    Compute \(\prob(E \ \text{or} \ F)\text{.}\)
    🔗
    🔗

    (b)

    Is \(E\) disjoint from \(F\text{?}\)
    🔗
    🔗

    (c)

    Find an event that is disjoint from \(E\text{,}\) but not from \(F\text{.}\)
    🔗
    🔗

    (d)

    Compute \(\prob(E \ \text{or} \ G)\text{.}\)
    🔗
    🔗

    (e)

    Compute \(\prob(F \ \text{or} \ G)\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Intro to Statistics

    Definition 1.1.12.

    A datum is a single recorded observation or measurement.
    🔗
    🔗

    Definition 1.1.13.

    Statistics is the science of collecting, organizing, and analyzing data.
    🔗
    🔗

    Definition 1.1.14.

    In a statistical experiment, a population is the set of all observations or measurements that could be collected.
    🔗
    🔗

    Definition 1.1.15.

    A characteristic of a population (e.g. proportion, average, etc.) is called a parameter.
    🔗
    🔗

    Definition 1.1.16.

    Rarely can we collect data on an entire population. Similarly, parameters are rarely exactly known. Realistically, we may collect data from a representative group selected from the population. This group is called a sample and the estimate for the parameter that we can measure from the sample is called a statistic.
    🔗
    🔗

    Checkpoint 1.1.17.

    Consider trying to learn the most common age among all students at SVSU. We might not be able to reach every single student enrolled, but we can reach everyone in this classroom right now. Computing the most common age (statistic) among all students in the classroom (sample) would be an estimate for the most common age (population) on campus (the population).
    🔗
    Reflect on the design of this experiment. In what ways could we adapt our experiment to improve the accuracy of our measurement?
    🔗
    🔗

    Definition 1.1.18.

    Typically, we record more than a single type of data in each experiment. Each characteristic recorded in a set of data is called a variable.
    🔗
