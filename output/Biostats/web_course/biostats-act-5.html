    🏫 Activity 2.5 🏫 Activity 5 - Boxplots
    

    This assignment is due at the beginning of class on Wednesday, September 23. It is graded based on completeness according to the rubric available on Canvas. It is open notes and collaboration with your group members is encouraged.
    🔗
    This activity is part of your final project. Extra care should be taken in completing this activity.
    🔗

    1.

    Prep Work: Record your answers to the following prompts in your prep work journal. Your answers should be the only material entered into your journal. Do not include supporting definitions, theorems, examples, or remarks of any kind.
    🔗

    (a)

    What statistics are comprise the 5 number summary?
    🔗
    🔗
    🔗

    2.

    Create a new RStudio script named SECTION#_LASTNAME_FIRSTNAME_Activity5.r. Then follow the procedure below. When you have finished the procedure, please submit your R script to the "Activity 5" assignment on Canvas.
    🔗

    (a)

    Import the library ggplot2 and build the data set for your group’s final project.
    🔗
    🔗

    (b)

    We will use the same quantitative variable in this portion of the project that you used in the Histograms portion of the project. Use the summary command to build its 5 number summary. Write the summary in the space below.
    🔗
    🔗

    (c)

    Create a new ggplot based on your data set that uses mapping=aes(y=your_var_from_part_a). Add to it a geom_boxplot().
    🔗
    🔗

    (d)

    According to your plot, how many outliers does this variable have? How can you tell?
    🔗
    🔗

    (e)

    Let’s emulate a clustered sample. Choose a qualitative variable from your data set that doesn’t have too many different outcomes. Then, create a boxplot for the variable you chose in part (a) for each cluster by changing our mapping to be mapping=aes(x=qual_var, y=quant_var).
    🔗
    🔗

    (f)

    Using the plot you generated in part (d), answer each of the following questions. Be sure to explain how you got each answer.
    🔗

    (i)

    Which has the widest IQR?
    🔗
    🔗

    (ii)

    Which has the greatest number of outliers?
    🔗
    🔗

    (iii)

    Which has the smallest median?
    🔗
    🔗
    🔗
    🔗

    3.

    Written Report: This portion of your written report should respond to each of the following prompts.
    1. Explain any techniques used to clean your data (if applicable).
      🔗
      🔗
    2. Include the single and clustered boxplots.
      🔗
      🔗
    3. Use the single boxplot to explain the shape of your data.
      🔗
      🔗
    4. Do you notice any trends/patterns in your data by clustering it?
      🔗
      🔗
    5. In this Histograms portion of the assignment, you were asked to draw conclusions about your data set from the histograms you generated. Explain how you could draw the same conclusions from your boxplots.
      🔗
      🔗
    When your rough draft is complete, your team lead should submit it in PDF format along with your team’s R script to the "📊Boxplots Check-in" assignment on Canvas (see Week 4 module).
