    Section 3.5 Variation of Parameters

    Objectives

    Students will be able to...
    🔗
    1. Apply the variation of parameters formula to find particular solutions.
      🔗
      🔗
    🔗
    Let us consider a more general approach to finding particular solutions to the differential equation
    \begin{equation*} y'' + P(x)y' + Q(x)y = f(x). \end{equation*}
    Suppose we have found the fundamental solutions \(y_1, y_2\) already. It is reasonable to assume that a particular solution may have a similar form, but the complementary solution already accounts for any linear combination we could take of these functions. So instead, we will need to take a nonlinear combination of some kind. One way to think about this combination is by allowing the parameters to vary in our complementary solution. That is
    \begin{equation*} y_c = c_1 y_1 + c_2 y_2 \implies y_p = \mu_1 y_1 + \mu_2 y_2. \end{equation*}
    🔗
    Suppose the particular solution does actually have this form. Substituting into the DE we get
    \begin{align*} y_p'' + P(x) y_p' + Q(x) y \amp = [ \mu_1 y_1'' + 2\mu_1' y_1' + y_1 \mu_1'' + \mu_2y_2'' + 2\mu_2'y_2' + \mu_2''y_2 ] \\ \amp + P(x) [ \mu_1'y_1 + \mu_1 y_1' + \mu_2' y_2 + \mu_2 y_2' ] + Q(x) [\mu_1 y_1 + \mu_2 y_2]\\ \amp = \mu_1 [y_1'' + Py_1' + Qy_1] + \mu_2[y_2'' + Py_2' + Qy_2] \\ \amp + \mu_1''y_1 + \mu_1'y_1' + \mu_2''y_2 + \mu_2'y_2' + P[\mu_1'y_1 + \mu_2'y_2] + \mu_1'y_1' + \mu_2'y_2' \\ \amp = \deriv{}{x} [\mu_1' y_1 + \mu_2' y_2] + P[\mu_1' y_1 + \mu_2' y_2] + [\mu_1' y_1' + \mu_2' y_2'] \\ \amp = f(x) \end{align*}
    🔗
    Without loss of generality, we can assume that
    \begin{equation*} \mu_1' y_1 + \mu_2' y_2 = 0. \end{equation*}
    Taking this assumption would result in the work above simply reading
    \begin{equation*} \mu_1' y_1' + \mu_2' y_2' = f(x). \end{equation*}
    In this way, we have built two equations for the unknowns \(\mu_1', \mu_2'\text{.}\) Using Cramer’s rule to solve the system of equations gives
    \begin{equation*} \mu_1' = \frac{W_1}{W} \ \text{and} \ \mu_2' = \frac{W_2}{W} \end{equation*}
    where \(W \) is the Wronskian of the fundamental solutions and \(W_k\) is the Wronskian with the \(k\)th column replaced by \(\begin{bmatrix} 0 \amp 0 \amp \cdots \amp f(x) \end{bmatrix}^T \text{.}\)
    🔗
    Integrating one more time produces the particular solution
    \begin{equation*} y_p = \mu_1 y_1 + \mu_2 y_2 = \left( \int \frac{W_1}{W} \, dx \right) y_1 + \left( \int \frac{W_2}{W} \, dx \right) y_2. \end{equation*}
    🔗

    Example 3.5.1.

    Solve
    \begin{equation*} y'' + y = \tan(x) \end{equation*}
    with varation of parameters.
    🔗
    Solution.
    We need to compute the complementary solution first. Notice the characteristic polynomial is
    \begin{equation*} \lambda^2 + 1 \end{equation*}
    which has roots \(\lambda = \pm i\text{.}\) Hence, the complementary solution is
    \begin{equation*} c_1 \cos(x) + c_2 \sin(x) \text{.} \end{equation*}
    Now that we have the fundamental solutions, we can compute the Wronskians we need in order to solve with variation of parameters. They are
    \begin{align*} W \amp = \begin{vmatrix} \sin(x) \amp \cos(x) \\ \cos(x) \amp -\sin(x) \end{vmatrix} \amp = 1 \\ W_1 \amp = \begin{vmatrix} 0 \amp \cos(x) \\ \tan(x) \amp -\sin(x) \end{vmatrix} \amp = -\sin(x) \\ W_2 \amp = \begin{vmatrix} \sin(x) \amp 0 \\ \cos(x) \amp \tan(x) \end{vmatrix} \amp = \sec(x)\tan(x) \end{align*}
    Thus, we can compute
    \begin{align*} \mu_1 \amp = \int \frac{W_1}{W} \, dx = \int -\sin(x) \, dx = \cos(x) \\ \mu_2 \amp = \int \frac{W_2}{W} \, dx = \int \sec(x)\tan(x) \, dx = \sec(x) \end{align*}
    Therefore, the particular solution is
    \begin{equation*} y_p(x) = \cos^2(x) + \tan(x) \end{equation*}
    and the general solution is
    \begin{equation*} y(x) = c_1 \cos(x) + c_2 \sin(x) + \cos^2(x) + \tan(x). \end{equation*}
