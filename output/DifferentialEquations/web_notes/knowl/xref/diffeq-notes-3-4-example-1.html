Example 3.4.1.

Solve
\begin{equation*} y'' + y' - 6y = 2x \end{equation*}
using undetermined coefficients.
🔗
Solution.
Recall that the general solution has the form \(y = y_c + y_p \text{.}\) Hence, with all nonhomogeneous linear ODEs, we must first start by solving the complementary equation
\begin{equation*} y'' + y' - 6y = 0 \end{equation*}
The roots of the characteristic polynomial are \(\lambda = -3, 2 \text{.}\) Hence, the complementary solution is
\begin{equation*} y_c(x) = c_1 e^{-3x} + c_2 e^{2x}. \end{equation*}
Next, we need to find the particular solution. Notice that our complementary solution has no way of generating a term that looks like \(2x \) as we take its derivatives. This tells us there must be some other piece of the puzzle contained by our particular solution. Intuition would tell us that we should have a linear component to our solution, so we might try a solution of the form \(\tilde{y} = Ax + B \text{.}\) This would give
\begin{equation*} y'' + y' - 6y = A - 6(Ax + B) = -6Ax + (B + A) = 2x. \end{equation*}
From this one equation, we can build two equations to solve for our undetermine coefficients. The coefficients on the linear terms should match, so
\begin{equation*} -6A = 2 \implies A = -\frac{1}{3} \end{equation*}
and we should not have a constant term, so
\begin{equation*} B + A = 0 \implies B = \frac{1}{3}. \end{equation*}
Therefore, the particular solution is
\begin{equation*} y_p = -\frac{1}{3} x + \frac{1}{3} \end{equation*}
and the general solution is
\begin{equation*} y = c_1 e^{-3x} + c_2 e^{2x}-\frac{1}{3} x + \frac{1}{3}. \end{equation*}
