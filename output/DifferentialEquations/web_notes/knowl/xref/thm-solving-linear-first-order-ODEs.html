Theorem 2.3.2.

We can follow the following steps to solve first-order, linear, ODEs.
  1. Write the equation in standard form.

    🔗
  2. Compute the integrating factor \(e^{\int P(x) \, dx} \text{.}\)
    🔗
    🔗
  3. Write the equation using the product rule.
    🔗
    🔗
  4. Integrate both sides to find the general solution.
