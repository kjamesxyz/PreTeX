    Section 6.2 Power Series Solutions at Ordinary Points

    Objectives

    Students will be able to...
    🔗
    1. Distinguish between ordinary and singular points.
      🔗
      🔗
    2. Find power series solutions to ODEs centered at ordinary points.
      🔗
      🔗
    🔗

    Definition 6.2.1.

    Consider the differential equation (in standard form)
    \begin{equation*} y'' + P(x) y' + Q(x) y = f(x). \end{equation*}
    We call the point \(x=x_0\) nonsingular if \(P,Q\) are “analytic” at \(x=x_0\text{.}\) Otherwise, we call it singular
    🔗
    🔗

    Theorem 6.2.2.

    Every second-order linear ODE has two linearly independent power series solutions centered about its ordinary points.
    🔗
    🔗

    Example 6.2.3.

    Find two linearly-independent solutions to the IVP
    \begin{equation*} (x-1)y'' - xy' + y = 0; \ y(0)=-2, \ y'(0) = -6 \end{equation*}
    🔗
    Solution.
    Notice that
    \begin{equation*} y'' - \frac{x}{x-1}y' + \frac{1}{x-1}y = 0 \end{equation*}
    only has singular points at \(x=1\text{.}\) So, we can assume that the solutions have the form
    \begin{equation*} y(x) = \sum_{n=0}^\infty c_n x^n. \end{equation*}
    If they satisfy the ODE, then we should have
    \begin{equation*} (x-1)\deriv{^2}{x^2} \left[ \sum_{n=0}^\infty c_n x^n \right] - x \deriv{}{x} \left[ \sum_{n=0}^\infty c_n x^n \right] + \left[ \sum_{n=0}^\infty c_n x^n \right] = 0. \end{equation*}
    Taking the derivatives gives us
    \begin{equation*} (x-1)\left[ \sum_{n=0}^\infty c_n n (n-1) x^{n-2} \right] - x \left[ \sum_{n=0}^\infty c_n nx^{n-1} \right] + \left[ \sum_{n=0}^\infty c_n x^n \right] = 0 \end{equation*}
    But now we have introduced zero terms. We can write this
    \begin{equation*} (x-1)\left[ \sum_{n=2}^\infty c_n n (n-1) x^{n-2} \right] - x \left[ \sum_{n=1}^\infty c_n nx^{n-1} \right] + \left[ \sum_{n=0}^\infty c_n x^n \right] = 0 \end{equation*}
    We can now incorporate the coefficients.
    \begin{equation*} \left[ \sum_{n=2}^\infty c_n n (n-1) x^{n-1} \right] - \left[ \sum_{n=2}^\infty c_n n (n-1) x^{n-2} \right] - \left[ \sum_{n=1}^\infty c_n nx^n \right] + \left[ \sum_{n=0}^\infty c_n x^n \right] = 0 \end{equation*}
    We would like to be able to combine like terms here, but we can’t for two reasons: The powers of \(x\) don’t match and neither do the starting points. Let’s tackle them in order. We would like to count the powers of \(x\) the same way in each power series, so we will introduce a dummy index \(k\text{.}\) In the first power series, if we write
    \begin{equation*} k=n-1 \leftrightarrow n = k + 1. \end{equation*}
    So we get
    \begin{equation*} \left[ \sum_{k=1}^\infty c_{k+1} (k+1) k x^k \right] - \left[ \sum_{k=0}^\infty c_{k+2} (k+2) (k+1) x^k \right] - \left[ \sum_{k=1}^\infty c_k k x^k \right] + \left[ \sum_{k=0}^\infty c_k x^k \right] = 0 \end{equation*}
    Next, it is typically easiest to increase starting points by stripping out terms. We write
    \begin{equation*} \left[ \sum_{k=1}^\infty c_{k+1} (k+1) k x^k \right] - 2c_2 - \left[ \sum_{k=1}^\infty c_{k+2} (k+2) (k+1) x^k \right] - \left[ \sum_{k=1}^\infty c_k k x^k \right] + c_0 + \left[ \sum_{k=1}^\infty c_k x^k \right] = 0 \end{equation*}
    Now that each series starts from \(k=1\) and has a common factor of \(x^k\text{,}\) we can combine them into the single power series below.
    \begin{equation*} c_0 - 2c_2 + \sum_{k=1}^\infty \left( c_{k+1}(k+1)k + c_{k+2}(k+2)(k+1) - c_k k + c_k \right) x^k = 0 \end{equation*}
    We can think of the RHS as the power series
    \begin{equation*} 0 = \sum_{k=1}^\infty 0 \cdot x^k. \end{equation*}
    In this light, we see that each coefficient MUST be zero. This tells us two things.
    \begin{equation*} c_0 - 2c_2 = 0 \implies c_2 = \frac{1}{2}c_0 \end{equation*}
    It also shows
    \begin{equation*} c_{k+2} = \frac{c_k k - c_k + c_{k+1}(k+1)k}{(k+2)(k+1)} \end{equation*}
    Now, applying our initial conditions, we see
    \begin{equation*} y(0) = \sum_{n=0}^\infty c_k \cdot 0^k = -2 \end{equation*}
    This shows that \(c_0 = -2\text{.}\) Now we also know that \(c_2 = -1\text{.}\) Using the other condition
    \begin{equation*} y'(0) = \sum_{n=1}^\infty c_k k 0^{k-1} = -6. \end{equation*}
    This shows that \(c_1 = -6\text{.}\) In this way, we can use our three-term recurrence relation to determine the rest of the constants. For example,
    \begin{equation*} c_3 = \frac{c_1 - c_1 + 2c_2}{3(2)} = -\frac{1}{3} \end{equation*}
    We can now write the solution as
    \begin{equation*} y(x) = -2 - 6x - 2x^2 - \frac{1}{3}x^3 - \cdots \end{equation*}
    🔗
    🔗
    🔗

    Definition 6.2.4.

    Suppose the linear ODE of the form
    \begin{equation*} \deriv{^ny}{x^n} + a_{n-1}(x) \deriv{^{n-1} y}{x^{n-1}} + \cdots + a_1(x) \deriv{y}{x} + a_0(x) y = f(x). \end{equation*}
    has a singular point at \(x = x_0\text{.}\) We call that point regular if \((x-x_0)^k a_{n-k}(x) \) are differentiable for all \(k\text{.}\) Otherwise, we call the point irregular.
    🔗
    🔗

    Theorem 6.2.5.

    Suppose \(x=x_0\) is a regular singular point. Then there exists at least one solution of the form
    \begin{equation*} y(x) = \sum_{n=0}^\infty c_0 (x - x_0)^{k + r} \end{equation*}
    where \(r \in \real \) is called the index of the solution.
    🔗
    🔗

    Example 6.2.6.

    Find a general power series solution to
    \begin{equation*} 2xy'' - y' + 2y = 0 \end{equation*}
    on \([0,\infty)\text{.}\)
    🔗
    Solution.
    First, we write the equation in standard form.
    \begin{equation*} y'' - \frac{1}{2x}y' + \frac{1}{x}y = 0 \end{equation*}
    Notice that \(x = 0\) is a singular point. Luckily, it is regular since
    \begin{align*} x \cdot -\frac{1}{2x} \amp= -\frac{1}{2} \\ x^2 \cdot \frac{1}{x} \amp= x \end{align*}
    are both differentiable at \(x=0\text{.}\) Frobenius’ theorem tells us that there is at least one solution of the form
    \begin{equation*} y(x) = \sum_{n=0}^\infty c_n x^{k + r} \end{equation*}
    where the index \(r=0\) is yet to be determined. Derivatives are
    \begin{align*} y'(x) \amp= \sum_{n=0}^\infty c_0 (k+r) x^{k+r-1} \\ y''(x) \amp= \sum_{n=0}^\infty c_0(k+r)(k+r-1)x^{k+r-2} \end{align*}
    Notice we cannot cancel terms out without knowing the value of \(r\text{.}\) Plugging into the equation we get
    \begin{equation*} 2x \left[ \sum_{n=0}^\infty c_0(k+r)(k+r-1)x^{k+r-2} \right] - \left[ \sum_{n=0}^\infty c_0 (k+r) x^{k+r-1} \right] + 2 \left[ \sum_{n=0}^\infty c_n x^{k + r} \right] = 0 \end{equation*}
    We can factor out a common factor of \(x^r\) which will contribute no information to the solution. So we “divide it out”. Reindexing, we get
    \begin{equation*} \frac{2c_0r(2r - 3)}{x} + \sum_{k=0}^\infty \left( c_{k+1}(k+r+1)(2k+2r-1) + 2c_k \right) x^k = 0. \end{equation*}
    The indical equation tells us
    \begin{equation*} \frac{2c_0r(2r - 3)}{x} = 0 \iff c_0 = 0, r = 0, r = \frac{3}{2}. \end{equation*}
    The recurrence relation gives
    \begin{equation*} c_{n+1} = -\frac{2c_n}{(n+r+1)(2n+2r-1)}. \end{equation*}
    Notice if \(c_0 = 0\) we must have the trivial solution. Let’s ignore this case. When \(r = 0\) we get
    \begin{equation*} c_{n+1} = -\frac{2c_n}{(n+1)(2n-1)} \end{equation*}
    and when \(r=\frac{3}{2}\) we get
    \begin{equation*} c_{n+1} = -\frac{4c_n}{(2n+5)(2n+2)}. \end{equation*}
    Therefore, we have
    \begin{align*} y_1(x) \amp= 1 + 2x - 2x^2 + \frac{4}{9}x^3 + \cdots \\ y_2(x) \amp= x^{\frac{3}{2}} \left[ 1 - \frac{2}{5}x + \frac{2}{35}x^2 - \frac{4}{2835}x^3 + \cdots] \end{align*}
    and the general solution is still \(y(x) = C_1 y_1 + C_2 y_2. \text{.}\)
